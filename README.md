# Amazon Predictive Analysis System using Machine Learning

A complete **end-to-end Machine Learning project** developed to analyze Amazon sales data, identify hidden patterns, and generate predictive insights for better decision-making. This project focuses on building a practical ML workflow involving **data preprocessing, exploratory data analysis (EDA), model development, evaluation, and deployment**.

---

## Project Overview

The main objective of this project is to analyze structured Amazon sales data and apply machine learning techniques to understand trends, improve prediction quality, and support data-driven decision-making.

The project workflow includes:

- Data Collection & Preprocessing  
- Handling Missing Values & Outliers  
- Feature Engineering & Scaling  
- Exploratory Data Analysis (EDA)  
- Training & Comparing Multiple ML Models  
- Model Evaluation & Performance Analysis  
- Deployment using Streamlit for Interactive Predictions

This project provided hands-on experience in working with **machine learning pipelines, predictive analytics, model comparison, and deployment workflows**.

---

## Key Features

### Data Cleaning & Preprocessing
- Processed raw datasets by handling missing values, inconsistent records, and outliers.
- Improved data quality for better model performance.

### Exploratory Data Analysis (EDA)
- Analyzed feature relationships and hidden patterns in Amazon sales data.
- Generated visual insights for better understanding of data trends.

### Feature Engineering & Scaling
- Applied label encoding and feature scaling techniques.
- Improved model efficiency and learning performance.

### Multiple Machine Learning Models
Implemented and compared multiple supervised and unsupervised machine learning algorithms.

### Model Evaluation
Compared model performance using:
- Accuracy Score
- Precision, Recall & F1-Score
- Confusion Matrix
- Classification Report
- ROC-AUC Curve

### Interactive Streamlit Application
- Built a user-friendly interface for predictions and analytics.
- Enabled interactive user experience for better visualization.

## Installation & Setup

Clone the repository:

```bash
git clone <your-repository-link>
```

Move to project directory:

```bash
cd amazon-predictive-analysis
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit App:

```bash
streamlit run app/streamlit_app.py
```
